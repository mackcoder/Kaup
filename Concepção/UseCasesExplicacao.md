# ⚙️Fluxo Básico do Sistema

| Passo | Ator | Ação |
|---|---|---|
| 1 | Usuário | Envia o contrato (imagem ou arquivo) |
| 2 | Sistema | Recebe o contrato e aciona o agente de IA |
| 3 | Agente IA | Analisa o contrato, extraindo o texto via OCR |
| 4 | Agente IA | Solicita dados adicionais necessários ao usuário |
| 5 | Usuário | Envia os dados solicitados |
| 6 | Agente IA | Gera e envia o relatório/análise do contrato |
