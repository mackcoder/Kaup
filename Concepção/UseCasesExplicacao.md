# Casos de Uso e Modelo de Casos de Uso

## Fluxo Básico do sistema:
1.  Usuário envia contrato (imagem, arquivo) 
2.  Sistema recebe contrato e ativa agente IA
3.  Agente IA analisa contrato e extraindo texto via OCR
4.  Agente IA pergunta dados adicionais necessários 
5.  Usuário envia dados solicitados
6.  Agente IA envia relatório/análise do contrato
